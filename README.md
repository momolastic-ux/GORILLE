# 🦍 Objectif Gorille

L'appli qui transforme les gays en gorilles.  
Ouvre le lien → installe l'appli → deviens un gorille.

---

## Installation (2 secondes)

1. **Ouvre ce lien sur ton téléphone** :  
   👉 **[https://momolastic-ux.github.io/GORILLE/](https://momolastic-ux.github.io/GORILLE/)**

2. **Installe l'appli** :

   - **Android (Chrome)** : un bandeau en bas propose **"Installer l'application"** → tape dessus.
   - **iPhone (Safari)** : tape sur **"Partager"** → **"Sur l'écran d'accueil"** → "Ajouter".

C'est fini. L'icône 🦍 est sur ton bureau.

---

## 💀 Pourquoi cette appli

- **Sans machines, sans banc, sans sangles, sans ceinture.**  
- **Squat, Deadlift, OHP, Row.**  
- **Tu progresses ou t'es gay.**

Les niveaux :  
`Gay 🧒 → Fillette 🧚 → Petit zizi 🤏 → Sigma 🗿 → Maxi Testo 💪 → Gorille 🦍`
